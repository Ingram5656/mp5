# 键盘模拟组合键（v0.8.3）

没有接传感器时，用键盘代替传感器。v0.8.3 起，键盘可以模拟评估和成就会看的各种情况，不只是“做对了”的一局。
游戏里按 **F1** 随时查看全部按键；按住组合键时，屏幕底部会写出当前生效的组合。

## 两关通用

| 按键 | 作用 |
|---|---|
| 按住 Z | 加力慢（施力速度低） |
| 按住 X 或 Ctrl | 加力快（施力速度高） |
| 按住 1 – 5 | 力度档位：1 过轻 · 2 偏低 · 3 正好 · 4 偏高 · 5 超出（还没到“用力过猛”） |
| 按住 Shift | 用力过猛（气球爆 / 萝卜算一次失误） |
| 按住 G / H | 轻微 / 明显手抖（保持不稳） |
| 按住 S | 偏轴力矩 |
| 按住 P | 拔力过大 |
| 按住 F | 自动做标准动作，可以和上面所有键一起按 |
| F1 / F3 / Esc | 按键说明 / 调试信息 / 返回 |

## 关卡 A：拔萝卜

- ← / A / Q 向左推，→ / D / E 向右推，松开就回中。
- 力度档位要和方向键一起按：

| 档位 | 力矩 | 情况 |
|---|---|---|
| 1 | 0.075 N·m | 过轻，进不了绿区 |
| 2 | 0.16 N·m | 绿区下沿 |
| 3 | 0.225 N·m | 绿区中间（默认） |
| 4 | 0.29 N·m | 绿区上沿 |
| 5 | 0.35 N·m | 超过绿区，但不算用力过猛 |

- 按住 F 时自动左右交替摇动：推到位，保持 0.7 秒，回中停 0.3 秒，再换另一边。
- 按住 F + R 会一直推同一边，用来模拟“没有左右交替”。

## 关卡 B：兔子的气球

- → / D / E / ↑ / W 加力，← / A / Q / ↓ 松开。不按键时力矩停在原处。
- 加力的标准速度 = 当前气球的目标 ÷ 加力时间，正好贴着虚线圈走。Z 慢到 0.35 倍，会落在虚线圈后面；X 快到 3 倍，会漏气。
- 按住 1 – 5 时，力矩会自动走到对应档位（T = 当前目标，tol = 当前难度的容差）：

| 档位 | 力矩 | 情况 |
|---|---|---|
| 1 | T × 0.4 | 过轻 |
| 2 | T − 1.5·tol（至少 T × 0.6） | 偏低 |
| 3 | T | 正好 |
| 4 | T + 1.5·tol | 偏高 |
| 5 | 安全线以上、低于上限（约 0.37–0.39 N·m） | 出现拉伸纹，但不爆 |

- 按住 F 时自动按标准线吹气球，绑好后自动松开，再吹下一个。

## 常用组合（举例）

| 想模拟的情况 | 拔萝卜 | 气球 |
|---|---|---|
| 标准的一局 | F | F |
| 施力速度高 | F + X | F + X（会漏气） |
| 施力速度低 | F + Z | F + Z（落后虚线圈） |
| 施力过轻 | F + 1 | F + 1 |
| 力矩偏低 / 偏高 | F + 2 / F + 4 | F + 2 / F + 4 |
| 超出目标但不过猛 | F + 5 | F + 5 |
| 保持时手抖 | F + G 或 F + H | F + G 或 F + H |
| 用力过猛 | F + Shift | F + Shift |
| 不左右交替 | F + R | — |
| 偏轴 / 拔力过大 | F + S / F + P | F + S / F + P |
