## 1. 设计依据：这个界面给谁用、在什么场景下用

- **对象：** 牙科学生在技能训练室里，一只手（或两只手）握着牙钳，夹在固定的模型牙上。
- **使用方式：** 视线在模型牙和屏幕之间来回切换，看屏幕的时间很短，屏幕离人大约 60–100 cm。
- **界面的首要任务：** 让操作者一眼看清“现在偏了没有、偏向哪边、还差多少”，并给出明确的通过/失败反馈。
- **你的要求：** 简洁、干净，不要过度华丽。

所以这个界面更像一台**校准过的测量仪器**，而不是网页或手机 App。风格取向是：读数清楚、颜色克制、状态明确。

## 2. 现状问题（v0.2.1）

v0.2.1 的样式是一套通用模板：浅灰背景、白色圆角卡片、蓝色强调色，所有内容都放在大小、圆角都一样的卡片里。它能用，但有三个问题：

1. **重点不突出。** 最重要的是实时读数，但读数只有 18 号字，和标题、目标说明差不多大。离远了看不清。
2. **颜色没有专门含义。** 蓝色同时表示按钮、选中状态和方向箭头，绿色既是目标区又是“已解锁”。操作者没法靠颜色判断状态。
3. **选择页结构平均。** 三张一样的卡片看不出先选什么、再做什么。

## 3. 设计令牌

### 色板（6 色 + 目标区底色）

| 名称 | 色值 | 只用在 |
| --- | --- | --- |
| Porcelain 瓷白 | `#F6F7F5` | 页面底色。偏冷的中性白，不用米黄色 |
| Slate 墨蓝灰 | `#1C2733` | 正文、读数、指针、主按钮底色 |
| Steel 钢灰 | `#8794A1` | 刻度、次要文字、未激活的轨道 |
| Target 目标青绿 | `#14A07A` | **只表示“当前在目标区内”**，以及保持满后的已解锁状态 |
| Target tint 目标区底色 | `#72C6AF` | 目标区在尚未进入时的颜色，约为目标青绿的 60% 浓度（v1.1 由 `#CDEEE3` 加深） |
| Caution 琥珀 | `#D99A00` | 接近边界、连接中 |
| Fault 警示红 | `#D2483E` | 失误、过载、断线 |

**规则：** 彩色只用来表示状态，界面里的其他东西都只用墨蓝灰和钢灰。主按钮用墨蓝灰实心，不用蓝色，选中状态用墨蓝灰描边。这样屏幕上一出现颜色，就是有事发生。

### 字体

- **拉丁字母和数字：** Atkinson Hyperlegible Next（Braille Institute 设计，SIL 开源许可）。这是专门为易读性设计的字体：0/O、1/l/I 等容易混淆的字形区分明显，适合远距离瞥一眼就读数。
- **中文：** Noto Sans SC（与思源黑体 SC 为同一设计，SIL 开源许可）。拉丁字母和数字仍由 Atkinson 显示，中文字符自动回退到 Noto Sans SC。
- **读数要用等宽数字，** 避免数字跳动时宽度变化导致抖动。字体是否支持等宽数字需要先确认；不支持的话就把读数放在固定宽度的框里。
- **字号阶梯（1.25 倍）：** 13 / 16 / 20 / 25 / 31 / 49。

| 用途 | 字号 | 字重 |
| --- | ---: | --- |
| 实时读数 | 49 | Bold |
| 页面标题 | 25 | Bold |
| 表名（方向、力、力矩） | 20 | Regular |
| 正文、按钮 | 16 | Regular |
| 目标说明、提示 | 13 | Regular |

正文和标题都用同一家族，靠字号和字重区分层级。英文标签用正常大小写，不用全大写。

### 形状

- 只有可以点击的东西（按钮、可选的游戏）用圆角（6 px）。
- 显示区域不用卡片框，用细分隔线分开。这一点来自你给的设计图：三个显示之间是竖线分隔。
- 不使用阴影和渐变。

## 4. 布局

### 入门测试页

三个显示是平行的同级信息，所以保持三栏，但去掉卡片框，改用竖向分隔线。读数放大到 49 号，放在每栏最显眼的位置。

```
┌──────────────────────────────────────────────────────────────┐
│ 拔牙训练装置                       ● 已连接（模拟）   EN | 中文 │
│ 入门测试                                                       │
├──────────────────────────────────────────────────────────────┤
│        方向         │          力          │        力矩       │
│                     │                      │                   │
│      ( 表盘 )        │       [力条]         │     ( 圆环 )       │
│                     │                      │                   │
│        42°          │        10.5 N        │     0.20 N·m      │  ← 49 号
│   目标 30–60°        │     目标 8–12 N       │  目标 0.15–0.25    │  ← 13 号
│   ▬▬▬▬▬▬▬ 已解锁      │   ▬▬▬▬ 保持中         │   ─── 未解锁       │
├──────────────────────────────────────────────────────────────┤
│ 模拟按键：左/右 方向  上/下 力  Q/E 力矩               操作说明 │
└──────────────────────────────────────────────────────────────┘
```

- 目标区平时用目标区底色 `#72C6AF` 显示，在白色表盘上要能一眼看到。
- **唯一的动效：** 指针在目标区内时，目标区从底色逐渐加深，保持满 1 秒时正好变成目标青绿 `#14A07A` 并解锁。离开目标区会立即回到底色。解锁后保持目标青绿，下方显示加粗的“已解锁”。其他地方都不加动效。

### 游戏选择页

选择是一个先后顺序：先选游戏，再选难度，最后开始。所以改成**左边列表、右边详情**，不再用三张相同的卡片。

```
┌──────────────────────────────────────────────────────────────┐
│ 拔牙训练装置                       ● 已连接（模拟）   EN | 中文 │
│ 游戏选择                                                       │
├──────────────────────┬───────────────────────────────────────┤
│ ▌摇牙挑战             │  摇牙挑战                               │
│   交替施力 · 力矩      │  练习左右交替施力和目标轴力矩             │
│ ─────────────────    │                                       │
│  拔牙导航             │           ( 大图标：力矩圆环 )           │
│   三维施力方向         │                                       │
│ ─────────────────    │  关卡 A  交替晃动                        │
│  精准拔出             │  关卡 B  力矩控制                        │
│   稳定拉力             │                                       │
│                      │  难度   [实习生] [见习医生] [大师牙医]     │
│                      │  简单：文字、颜色和力度指针提示 ……         │
│ 传感器自检             │                                [开始]  │
└──────────────────────┴───────────────────────────────────────┘
```

- 左栏是三行列表。选中的那一行左侧有一条墨蓝灰竖条，并改用粗体。
- 右栏显示所选游戏的详情：大图标、关卡、难度和“开始”按钮。
- “开始”按钮固定在右下角，这样视线最后落在这里。
- 内容统一左对齐，只有读数在各自的栏里居中。

## 5. 原则

1. **一眼可读：** 读数是整个界面最大的元素，在 1 米外也能看清。
2. **颜色只表示状态：** 青绿 = 在目标区，琥珀 = 接近边界或等待中，红 = 失误或故障。其他元素一律不用彩色。
3. **只在一处用力：** 视觉重点只给实时读数，标题、说明和按钮都保持安静。
4. **动效只回应状态变化：** 不加入场动画，也不加悬停动画。
5. **中英文同一版式：** 中文和英文用同一套字号阶梯，按钮宽度按较长的英文留够余量，切换语言时布局不跳动。
6. **色盲可读：** 状态除了颜色，还要有文字或形状区分（“已解锁”文字、失误时出现“×”标记），满足游戏设定里的无障碍要求。

## 6. 对照需求自查：哪些地方改掉了默认做法

| 最初的想法 | 为什么放弃 | 改成 |
| --- | --- | --- |
| 深色“医疗监护仪”风格，黑底配荧光绿 | 这是常见的现成套路，而且黑底荧光绿和“简洁、干净”的要求不符；训练室光线明亮，深色屏反光明显 | 浅色瓷白底，颜色只表示状态 |
| 继续用蓝色作主色 | 蓝色和方向箭头、选中状态混在一起，颜色失去含义 | 主色改为墨蓝灰，彩色只留给状态 |
| 三张相同的卡片 | 通用 SaaS 模板，看不出层级和先后顺序 | 测试页用分隔线三栏；选择页改成列表加详情 |
| 读数旁再加大标签和图标 | 增加装饰，和“简洁”冲突 | 读数本身放大，其余缩小 |
| 中英文分别用不同版式 | 增加维护工作，切换语言时布局会跳 | 同一版式、同一字号阶梯 |

## 7. 实施说明（Godot）

- 用一个 Theme 资源统一管理颜色、字体和按钮样式，不在每个控件上单独设置。
- 字体文件放在 `res://fonts/`（Atkinson Hyperlegible Next 与 Noto Sans SC 的 Regular、Bold，附 OFL 许可文本），已由 v0.3.0 加入。
- Noto Sans SC 单个字重约 10 MB。如果只需要界面里的固定文字，可以以后再做字体子集化。
- 每次实施都做成新版本，旧版本保留，方便对比（v0.3.0 → v0.3.1）。
