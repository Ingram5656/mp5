# MP5 app v0.2.0 (Godot 4.7)

Flow: sensor connection -> "How it works" -> entry test (three locks) -> "Connection successful" -> game selection.

## Run
Open `app_v0.2.0/main.tscn` in Godot and press F6.

## Game selection
- Three game cards: Rocking Challenge, Extraction Navigation, Precision Pull. Click a card to select it.
- Difficulty: Intern / Trainee Dentist / Master Dentist.
- Start: games are not built yet, so a "Coming soon" message is shown.
- Sensor check: repeats the entry test.

## Simulated input (keyboard)
Left / Right = direction, Up / Down = force, Q / E = moment.

Target ranges are placeholders for interface testing only, not validated or clinical values.
See `版本记录.md` in the project root for the change history.
