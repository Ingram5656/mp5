### 想法 1：兔子的气球

| 项 | 内容 |
|---|---|
| **核心玩法** | 加力 → 气球随力矩变大 → 跟着屏幕上的“标准加力线”慢慢把气球吹到目标大小并保持 → 绑到萝卜上；加力太快会漏气，超过上限会“砰”地爆掉 |
| **为什么做这个** | 拔牙要求持续、缓慢地加力，不能猛然发力。关卡 A 只练“推到区间”，没有练“加力有多快”。v0.5.2 的标准曲线评分可以直接用来衡量 |
| **3 秒画面亮点** | 气球一点点鼓起来；吹过头就“砰”，兔子被吓一跳，炸成一头乱毛 |
| **保留 / 改变（相对关卡 A）** | 保留：菜地画风、“进区间 → 保持”判定、失误次数和难度设置。改变：目标从固定区间变成一条随时间上升的曲线，并新增“加力速度”判定 |
| **内容生成** | 每个气球的目标值（0.15–0.35 N·m）和上升时间（2–4 s）按难度随机生成；程序检查目标不超过上限的 85%，保证能完成 |
| **结果展示** | 结算时兔子拎着一串气球，数量就是成功个数；评估报告里叠加“标准加力线”和实际曲线 |
| **训练指标** | 跟踪误差（加力阶段）、加力速度、超调量、保持稳定性、爆气球次数 |
| **最小版本范围** | 一个场景、一种气球、5 个气球一局、三档难度、接入评估报告和历史记录；约 1–1.5 周 |
| **最小版本不含** | 成就、多种气球外观、双向力矩（先只用一个方向） |
| **放弃条件** | 试点时，大多数人在实习生难度也无法完成 3 个气球，或者觉得“看不懂要跟着线走” |
| **风险** | ① 跟踪线太难看懂 → 实习生难度用气球外的虚线圈直接显示“现在应该多大”；② 只练一个方向 → 第二版加左右交替 |
| **评分** | 开发 4 · 内容 5 · 趣味 5 · 训练 5 · 区分 4 · 可测量 5 · 契合 4 = **32/35** |

### 想法 2：跷跷板

| 项 | 内容 |
|---|---|
| **核心玩法** | 跷跷板一头放 1–3 根萝卜（对应不同的力矩），施力让跷跷板保持水平 1.5 秒算成功；超过上限，兔子被弹飞 |
| **为什么做这个** | 练的是“不同大小的力矩都能用准”，关卡 A 的目标区间一直是同一个 |
| **3 秒画面亮点** | 萝卜一根根放上去，跷跷板慢慢摆平；用力过猛时兔子被弹上天 |
| **保留 / 改变** | 保留：判定框架、画风、难度。改变：每一轮目标大小不同，左右两个方向都有 |
| **内容生成** | 6–8 轮的目标序列（大小、方向）随机生成，保证相邻两轮不重复 |
| **结果展示** | 结算时显示每一轮的“目标 vs 实际”小条形图 |
| **训练指标** | 每一级的平均误差、调整到位时间、超调量、保持稳定性 |
| **最小版本范围** | 一个场景、三级重量、6 轮一局；约 1 周 |
| **最小版本不含** | 成就、动态改变重量 |
| **放弃条件** | 试点时各级误差没有区别，说明分级没练出效果 |
| **风险** | ① 和关卡 A 的“进区间保持”感觉太像 → 用不同重量和水平仪画面强化“精准定量”；② 三级差距太小难以分辨 → 先拉开到 0.10 / 0.20 / 0.30 N·m |
| **评分** | 开发 4 · 内容 5 · 趣味 4 · 训练 4 · 区分 5 · 可测量 5 · 契合 4 = **31/35** |

### 想法 3：兔子唱歌

| 项 | 内容 |
|---|---|
| **核心玩法** | 力矩大小对应兔子唱的音高；音符从右边滑过来，在音符到达时把力矩调到对应高度并保持音符长度，唱完一小段旋律过关 |
| **为什么做这个** | 练快速、准确地在几档力度之间切换，最有游戏感 |
| **3 秒画面亮点** | 兔子随着你的力度唱出高低音，唱跑调时会破音 |
| **保留 / 改变** | 保留：画风、难度。改变：节奏由音乐决定，新增音效合成 |
| **内容生成** | 旋律可以从 3–5 个音阶自动生成，或者用几首无版权的简单儿歌（需要确认版权） |
| **结果展示** | 唱完显示“音准”评分，可以导出一段录音 |
| **训练指标** | 每个音符的误差、到位时间、切换时的超调 |
| **最小版本范围** | 3 个音高、1 段旋律；约 2 周（主要是音频部分） |
| **最小版本不含** | 多首歌、录音导出 |
| **放弃条件** | 试点时大家只顾跟节奏，力度控制明显变差 |
| **风险** | ① 节奏由游戏决定，与临床“自己控制节奏”不符 → 放慢速度、音符之间留回中时间；② 音频开发量大 → 先用简单的合成音 |
| **评分** | 开发 3 · 内容 4 · 趣味 5 · 训练 3 · 区分 5 · 可测量 4 · 契合 3 = **27/35** |

## 建议

先做 **兔子的气球**。它补上了关卡 A 完全没练到的“加力速度”，这正是临床最强调的一点；v0.5.2 已有的标准曲线评分可以直接复用；按 v0.5.4 的分层，只需新写一个规则模型、一个画面视图、一个主持者。**跷跷板** 分数只差 1 分，可以以后作为关卡 B 的第二种模式（练分级定量），或者留作关卡 C。
